Apps Script 연결이 필요해요

Google Sheets와 Apps Script를 연결하면 학생들이 바로 기록할 수 있어요.

  1. Google Sheets 새 파일 만들기

    sheets.new에 접속해 파일 이름을 정해요 (예: 영생고 생태지도 DB).

  2. Apps Script 편집기 열기

    확장 프로그램 → Apps Script → 기존 내용을 지우고 gas_backend.gs 내용을 붙여넣은 뒤 저장해요.

  3. 웹 앱으로 배포

    배포 → 새 배포 → 유형: 웹 앱, 실행 계정: 나, 액세스: 모든 사용자(익명 포함) → 배포 후 URL을 복사해요.

  4. index.html에 URL 붙여넣기

    index.html에서 GAS_URL을 찾아 복사한 URL로 바꿔요.

    const GAS_URL = '복사한 배포 URL';
  5. GitHub Pages에 올리기

    저장소에 index.html을 올리고 Settings → Pages → Branch: main → Save. 나온 주소를 학생들에게 공유해요.

Apps Script 코드를 고치면 새 배포를 만들거나 기존 배포의 버전을 올려야 바뀐 내용이 적용돼요. 배포 URL은 그대로예요.
