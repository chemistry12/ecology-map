영생고 생태지도 — Firebase 설정 필요
아래 안내를 따라 Firebase를 연결하면 학생들이 바로 사용할 수 있어요!
1
Firebase 프로젝트 만들기

console.firebase.google.com 접속 → 프로젝트 만들기 → 이름 입력 (예: yeongsaeng-ecology) → Google 애널리틱스 비활성화 → 만들기

2
Realtime Database 활성화

왼쪽 메뉴 → 빌드 → Realtime Database → 데이터베이스 만들기 → 지역: asia-southeast1 → 보안 규칙: 테스트 모드로 시작 → 사용 설정

3
웹 앱 구성 값 복사하기

프로젝트 개요 → 웹 아이콘 </> 클릭 → 앱 닉네임 입력 → 등록 → firebaseConfig 내용 복사

const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", databaseURL: "https://your-project-rtdb.asia-southeast1...", projectId: "your-project", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc123" };
4
index.html 파일에 붙여넣기

메모장 또는 VS Code로 index.html 열기 → 파일 상단에서 FB_CONFIG를 찾아 복사한 값으로 교체

// ← 이 부분을 찾아서 교체하세요 const FB_CONFIG = { apiKey: "여기에 복사한 값", ... };
5
GitHub Pages에 업로드

GitHub → 새 저장소 → 이름: ecology-map → index.html 업로드 → Settings → Pages → Branch: main → Save → URL 학생들에게 공유!

⚠️ Firebase 무료 티어 보안 주의: 테스트 모드는 30일 후 자동 만료됩니다. 이후 Realtime Database → 규칙 탭에서 아래 규칙을 붙여넣어 읽기/쓰기를 유지하세요:

{ "rules": { ".read": true, ".write": true } }
